\# My Portfolio Enhancements



This repository is my customized Azure Databricks medallion lakehouse portfolio project.



\## Changes I Added



\- Added a dedicated `docs/` folder for project documentation.

\- Added `sql/data\_quality\_checks.sql` with validation queries for the Silver layer.

\- Added `tests/test\_data\_quality.py` to document PySpark-style data quality test logic.

\- Added `config/pipeline\_config.json` to describe project metadata, data layers, and validation rules.

\- Added `.gitignore` for Python, Databricks, local output, and secret files.

\- Reworked the repository structure to make the project easier to understand as a portfolio project.



\## Learning Goals



This project demonstrates:



\- Bronze, Silver, and Gold medallion architecture

\- Data cleaning and validation logic

\- Referential integrity checks

\- Portfolio-ready documentation

\- Azure Databricks lakehouse project organization
